# Texture credits

All surface textures are from [Poly Haven](https://polyhaven.com) and released under **CC0** (public domain). No attribution is required; it is listed here for reference. Images were downscaled to 512–1024 px and re-encoded as JPEG for phones.

| File prefix | Poly Haven asset | Used for |
|---|---|---|
| `thatch_` | [Reed Roof 04](https://polyhaven.com/a/reed_roof_04) | meditation hut thatch |
| `flagstone_` | [Stone Pathway](https://polyhaven.com/a/stone_pathway) | hut path |
| `sandstone_` | [Sandstone Blocks 04](https://polyhaven.com/a/sandstone_blocks_04) | carved and smooth stone everywhere: pillars, steps, lanterns, the hut plinth |
| `grass_` | [Grass Ground](https://polyhaven.com/a/grass_ground) | lawns |
| `planks_` | [Oak Wood Planks](https://polyhaven.com/a/oak_wood_planks) | hut floor and porch |
| `teak_` | [Dark Wood](https://polyhaven.com/a/dark_wood) | posts, beams, banner poles |
| `mossstone_` | [Mossy Sandstone](https://polyhaven.com/a/mossy_sandstone) | pond rocks |
| `slabs_` | [Marble 01](https://polyhaven.com/a/marble_01) | courtyard, plaza and paths (large cream slabs) |
| `ashlar_` | [Sandstone Blocks 08](https://polyhaven.com/a/sandstone_blocks_08) | temple walls, plinths and boundary walls |
| `cave_` | [Rock Face 03](https://polyhaven.com/a/rock_face_03) | the rock-cut prayer halls: walls, ceiling, pillars |
| `granite_` | [Rock Wall 08](https://polyhaven.com/a/rock_wall_08) | the prayer halls' shrine, steps and platform |

Each set has `_diff` (colour), `_nor` (OpenGL normal) and `_arm` (ambient occlusion, roughness, metalness).
